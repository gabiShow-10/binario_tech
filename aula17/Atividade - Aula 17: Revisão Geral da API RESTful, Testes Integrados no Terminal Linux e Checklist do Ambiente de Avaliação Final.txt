EXERCÍCIO 1:
Crie um script Bash chamado `testar_simulado.sh` que realize uma requisição `GET` para a rota `/api/v1/health` e grave o HTTP Status Code obtido em um arquivo chamado `health_check.log`.

#!/bin/bash

# Faz a requisição capturando apenas o HTTP Status Code e salva no log
STATUS_CODE=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/v1/health)

echo "[$(date '+%Y-%m-%d %H:%M:%S')] HTTP Status Code: $STATUS_CODE" >> health_check.log
echo "Status $STATUS_CODE registrado em health_check.log"


$ chmod +x testar_simulado.sh

EXERCÍCIO 2:
Adicione um endpoint POST `/api/v1/auth/token-teste` no servidor da Aula 17 que gere e devolva um JWT assinado válido por 5 minutos para os testes do simulado.

app.post('/api/v1/auth/token-teste', (req, res) => {
  const payload = {
    id: "aluno_123",
    nome: "Aluno Binario Tech",
    funcao: "Desenvolvedor"
  };

  const secret = process.env.JWT_SECRET || 'binario_tech_exame_2026_secreto';
  const token = jwt.sign(payload, secret, { expiresIn: '5m' });

  return res.json({ token });
});
